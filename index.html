Cara Menghubungkan ke Robot

  1. Flash firmware Bluetooth ke micro:bit: buka makecode.microbit.org → tambah ekstensi Bluetooth → tempel kode dari tab Editor Kode → Download ke papan.
  2. Buka file website ini langsung di Chrome atau Edge (Bluetooth tidak bisa di dalam preview/iframe).
  3. Pastikan Bluetooth perangkat menyala dan micro:bit dalam jangkauan.
  4. Matikan Mode Demo, lalu tekan tombol HUBUNGKAN KE MICRO:BIT dan pilih perangkat BBC micro:bit.
  5. Pill status jadi biru = tersambung. Robot kini dikendalikan beneran! 🎉

Butuh Chrome/Edge & konteks aman (HTTPS atau file lokal). Kalau muncul pesan “layanan UART tidak ada”, berarti firmware belum di-flash.

🧪

Cara Pakai Mode Demo

  1. Buka tab ⚙️ Pengaturan, atau pakai tombol cepat di bawah.
  2. Geser saklar Mode demo ke ON — atau klik tombol “Nyalakan Mode Demo”.
  3. Status jadi biru bertanda demo — sekarang coba Setir, Output, dan Sensor, semuanya bereaksi.
  4. Geser kembali ke OFF untuk berhenti dan kembali mencari robot asli.
💡

Penjelasan Tab Output & Tombol Papan

💡Lampu: saklar ON/OFF lampu depan + slider kecerahan (mengirim lamp:on / lamp:0–100).
🌀Kipas: tombol Mati, 1, 2, 3 untuk kecepatan kipas (fan:0–3).
⚙️Servo: dua slider mengatur sudut servo C dan X dari 0–180 derajat.
🔵Tombol A & B: mengirim perintah a / b ke papan (tombol di sebelah klakson pada tab Setir).
📣Klakson: tombol tengah mengirim horn; di simulasi berbunyi dua nada.
🚦

Arti Warna Status Koneksi

Merah = terputus (belum tersambung)
Kuning = sedang menyambung / mencari
Biru = tersambung (robot asli ATAU mode demo)
Perintah gerak: atas = up, bawah = down, kiri = left, kanan = right, berhenti = stop. Tab Output untuk lampu, kipas, dan servo. Tab Sensor menampilkan data dari papan secara langsung.

bluetooth.onBluetoothConnected(function () {
    basic.showIcon(IconNames.Happy)
})
bluetooth.onBluetoothDisconnected(function () {
    basic.showIcon(IconNames.Sad)
})
bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    receivedString = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))
    if (receivedString == "up") {
        pins.servoWritePin(AnalogPin.P0, 180)
        pins.servoWritePin(AnalogPin.P1, 0)
    }
    if (receivedString == "down") {
        pins.servoWritePin(AnalogPin.P0, 0)
        pins.servoWritePin(AnalogPin.P1, 180)
    }
    if (receivedString == "right") {
        pins.servoWritePin(AnalogPin.P0, 180)
        pins.servoWritePin(AnalogPin.P1, 180)
    }
    if (receivedString == "left") {
        pins.servoWritePin(AnalogPin.P0, 0)
        pins.servoWritePin(AnalogPin.P1, 0)
    }
    if (receivedString == "stop") {
        pins.servoWritePin(AnalogPin.P0, 90)
        pins.servoWritePin(AnalogPin.P1, 90)
    }
    if (receivedString.charAt(0) == "x") {
        pins.servoWritePin(AnalogPin.P2, parseFloat(receivedString.substr(1, 3)))
    }
    if (receivedString.charAt(0) == "c") {
        pins.servoWritePin(AnalogPin.P2, parseFloat(receivedString.substr(1, 3)))
    }
})

📟 Log Sistem

Mengenal data & aktivitas

Nilai sensor hanya berasal dari kiriman Bluetooth micro:bit. Jika belum ada data, nilainya “—”, bukan angka perkiraan.

TX

Perintah dicatat setelah penulisan Bluetooth selesai. TX bukan bukti robot sudah menjalankannya; periksa balasan RX dari firmware.

RX

Pesan masuk: nilai sensor atau balasan dari micro:bit melalui Bluetooth.

SYS

Aktivitas aplikasi, seperti proses koneksi dan pemutusan koneksi. Bukan hasil pengukuran sensor.

ERR

Kesalahan saat aplikasi bekerja, misalnya koneksi atau pengiriman yang gagal.

Mode Demo dicatat sebagai SYS dengan tanda [DEMO], bukan TX/RX perangkat asli. Daftar menyimpan maksimal 200 pesan terbaru. Bersihkan hanya menghapus tampilan riwayat, bukan mereset koneksi atau penghitung TX/RX.

📖 Cara Memakai

Flash program Bluetooth UART

Nyalakan papan micro:bit dan pastikan program Bluetooth UART sudah ter-flash dari MakeCode.

Tekan Hubungkan

Tekan tombol Hubungkan di kanan atas, lalu pilih perangkat BBC micro:bit pada dialog browser.

Pilih mode

Buka Sensor untuk grafik, atau Kontroler untuk mengemudikan robot.

Kendalikan robot

Gunakan D-pad, slider servo, lampu, kipas, dan gambar di matriks LED.

Periksa log

Buka tab Log Sistem untuk melihat seluruh paket TX/RX secara langsung.

💡 Tips

  • Gunakan Chrome, Edge, atau Opera terbaru — Web Bluetooth belum ada di Safari/Firefox.
  • Halaman harus dibuka lewat HTTPS atau localhost agar Bluetooth diizinkan.
  • Jaga jarak papan di bawah 10 meter dan hindari penghalang logam.
  • Tanpa papan fisik, aktifkan Mode Demo di Pengaturan untuk mencoba semua fitur.

🔧 Protokol UART

Papan mengirim data dengan format kunci:nilai per baris. Perintah keluar dikirim otomatis oleh tombol-tombol kontroler.

updownleftrightstophornabc0–180x0–180lamp:onlamp:80fan:0–3mode:autoled:010…

Data masuk yang dikenali: suhu, kelembaban, cahaya, suara, kompas, akselerasi (x), baterai.
